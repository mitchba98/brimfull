Install Agent

Run on each server you want to monitor:

curl -sSL {{ host_url }}/agent/agent.sh -o /usr/local/bin/brimfull-agent.sh
chmod +x /usr/local/bin/brimfull-agent.sh

Then add to crontab (crontab -e):

*/5 * * * * BRIMFULL_URL={{ host_url }} BRIMFULL_KEY={{ account.api_key }} /usr/local/bin/brimfull-agent.sh >> /var/log/brimfull-agent.log 2>&1

To use a custom display name instead of the system hostname:

*/5 * * * * BRIMFULL_URL={{ host_url }} BRIMFULL_KEY={{ account.api_key }} BRIMFULL_HOSTNAME=my-server /usr/local/bin/brimfull-agent.sh >> /var/log/brimfull-agent.log 2>&1
